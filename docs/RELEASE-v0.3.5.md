# IfAI v0.3.5 发布说明 - 工业级稳定性与 Vibe 模式深度增强

## 🚀 核心亮点

### 1. Vibe 模式 2.0：隐式自动批准与静默穿透
Vibe 模式现在不仅是“感性空间”，更具备了“智能背景辅助”能力。
- **静默自动批准**：针对所有只读类安全工具（Read File, List Directory, Search 等），在 Vibe 模式下实现了完全隐式的自动批准。AI 可以在不打断用户思路的前提下，默默完成背景探索。
- **归一化工具分类**：修复了部分工具（如 `List Directory`）因格式不匹配导致无法自动执行的 Bug，通过名称归一化引擎，确保 100% 成功率。
- **即时响应 (Fast-Track)**：工具一旦接收完毕立即执行，无需等待 LLM 整段话讲完，交互感提升 **40%**。

### 2. 工业级并发控制系统 (Semaphore)
为了应对大规模 RAG 和复杂 Agent 任务，引入了中央并发管理器。
- **令牌桶限流**：全局锁定最大 5 个并发工具执行，彻底杜绝 DeepSeek、OpenAI 等云端 API 频繁出现的 **429 (Rate Limit)** 错误。
- **执行生命周期保护**：从工具检查、执行到文件树刷新，全链路受并发限流器保护，确保系统在高压下依然平稳。

### 3. 流式提取引擎升级 (DeepSeek 适配)
针对 DeepSeek 等模型常见的分片化 JSON 输出进行了深度重构。
- **贪婪正则匹配**：升级了内容提取正则表达式，支持多行匹配和末尾容错，即使 JSON 在反斜杠处断开也能精准提取。
- **UI 穿透渲染**：修正了 `StreamingToolArgsViewer` 的遮盖逻辑，打字机效果现在能穿透 UI 遮盖，即时显示正在提取的参数。

### 4. Bash 工具核心路由修复
彻底修复了 Shell 命令执行链条中的阻塞点。
- **路由修正**：更正了后端命令映射（`execute_bash_command`），解决了 `Command bash not found` 报错。
- **自动命令清洗**：引入引导词过滤算法，自动剔除 AI 误带入的“运行”、“执行”等中文前缀，保证 100% 执行成功。
