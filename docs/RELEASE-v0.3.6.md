# IfAI v0.3.6 发布说明 - UI 工业级重构、PIVO 2.0 与全链路结构化

**发布日期**：2026-02-15
**版本号**：v0.3.6 (Stable)

IfAI v0.3.6 标志着产品从“功能堆叠”向“工业级架构”的全面跃迁。本版本完成了自项目启动以来最大规模的 UI 重构，并推出了代号为 **"PIVO 2.0"** 的高级指令引擎，实现了从用户意图到工具执行的全链路结构化闭环。

## 🌟 三大核心演进

### 1. 工业级 UI & 交互重构 (Pro-Grade UI)
我们重新审视了 AI 助手的每一处像素，旨在提供更纯粹、更高效的编码环境：
- **模型胶囊面板 (Model Capsule)**：位于输入区顶部的动态胶囊，实时显示当前模型提供商、协议状态及上下文消耗，支持一键极速切换模型。
- **多线程管理升级**：重构了 `ThreadTabs` 逻辑，支持会话的物理隔离与深度清理，大幅优化了大规模会话下的内存占用。
- **沉浸式输入体验**：深度优化的 `ChatInputArea` 现在支持更智能的 `#` 符号补全与 `@` 物理文件引用，配合全新的快捷键路由，操作行云流水。

### 2. PIVO 2.0 高级指令集 (Intelligence Engine)
PIVO (Plugin-Integrated Verified Operations) 引擎迎来 2.0 时代：
- **风险感知决策**：全新的 `RiskPolicy` 能够智能识别“写操作”与“破坏性操作”，在 `Spec` 模式与 `Vibe` 模式之间实现动态平衡。
- **全执行器架构 (Executors)**：将执行逻辑彻底解耦为 `FileSystem`, `Shell`, `Search`, `Symbol` 四大核心执行器，支持异步结果预览与 Diff 对比。
- **工业级批处理**：支持单次指令触发多个并行工具调用，并提供统一的结构化审批视图，效率提升 300%。

### 3. 全链路结构化闭环 (Structured Output)
数据不再只是文本，而是具有生命力的结构化实体：
- **图形化消费 (PivoProjectTree)**：工具生成的扫描结果、搜索结果不再堆砌在聊天框中，而是直接转化为 `PivoProjectTree` 中的交互式节点，支持点击跳转与二次操作。
- **引用物理化注入**：所有通过 `@` 或 `#` 引用的实体均通过后端 `SymbolEngine` 进行物理化解析，注入到上下文中的是经过精简的精准片段，而非全量文件。
- **鲁棒的解析流水线**：重写了流式 JSON 解析逻辑，能够从复杂的推理模型（如 GLM5）混合输出中精准提取工具调用指令。

## 🛠 模型生态扩展

- **NVIDIA NIM & GLM-5 深度适配**：完美适配了 NVIDIA 平台的思维链协议，解决了推理模型常见的 `system` 消息兼容性问题。
- **Token 计数升级**：支持对 `z-ai/glm5` 等复合命名的模型进行精准 Token 计算与上下文窗口管理。
