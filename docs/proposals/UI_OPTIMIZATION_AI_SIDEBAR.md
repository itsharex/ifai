# AI 侧边栏 UI 工业级优化提案 (修订版)

> **提案编号**: UI-OPT-001-REV1
> **目标版本**: v0.3.6
> **优先级**: P1 - 高优先级
> **状态**: 待审核 (已根据用户反馈及顶级设计师评审修订)

---

## 📋 执行摘要

### 当前问题
AI 侧边栏（红框区域）存在以下工业级体验缺陷：
- **垂直空间浪费严重**：不常用的“搜索对话框”占据固定位置；模型选择器样式笨重。
- **视觉层级混乱**：Logo、选择器、按钮堆叠，缺乏清晰的视觉分组。
- **信息密度不均**：对话列表项高度不一，视觉节奏混乱。
- **交互路径过长**：模型切换需要点击两次独立的下拉框。

### 优化目标
- **极致空间利用**：通过“按需展开”搜索和“胶囊化”选择器，节省至少 80px 的垂直空间。
- **信息密度提升 40%**：单屏可多展示 2-3 个会话。
- **视觉层级清晰**：建立明确的 Z 轴层级和品牌化视觉。
- **响应式完善**：支持从 64px (极简) 到 480px (专业) 的自适应。

---

## 🎯 优化范围

### 重点重构区域：
1. **Header 品牌区** - Logo 紧凑化，版本徽章移位。
2. **控制中心 (Control Capsule)** - 合并 Provider + Model 选择器为单体胶囊。
3. **按需搜索 (On-demand Search)** - 将搜索框改为隐藏式，通过图标或快捷键激活。
4. **视图切换** - 采用分段控制器 (Segmented Control)，取代笨重的按钮。

---

## 🔧 详细优化方案

### 1. Header 与控制胶囊重构

#### 方案细节
**引入“全能胶囊” (All-in-one Capsule)**：

```
┌─────────────────────────────────────┐
│ 🤖 IfAI Editor          v0.3.5 PRO  │  ← 品牌行 (32px)
├─────────────────────────────────────┤
│ [ 🧠 DeepSeek / V3 ▼ ]       🔍  ⚙️ │  ← 胶囊化控制行 (36px)
└─────────────────────────────────────┘
```

**具体改动**：
- **胶囊按钮**：合并 Provider 图标 + 模型短名称。点击弹出类似于 IDE **Command Palette** 的浮动面板。
- **搜索入口**：搜索框默认折叠，仅保留 🔍 图标。
- **设置按钮**：低频操作，整合进胶囊面板或搜索栏末端。

---

### 2. 按需搜索 (On-demand Search)

#### 优化逻辑
搜索对话是一个低频操作（≤10% 使用率），不应占据常驻空间。

#### 方案细节
- **默认状态**：隐藏搜索框。
- **触发方式**：点击 Header 上的 🔍 图标或快捷键 `Cmd + F`。
- **呈现方式**：以 **Slide-down (下拉)** 动画在 Header 下方展示。
- **收益**：**立即节省 48px 常驻高度。**

---

### 3. 会话列表增强

#### 视觉规范
- **高度统一**：48px。
- **选中指示器**：左侧 3px 亮蓝色竖条 + `#252526` 背景填充。

#### 智能增强 (Smart Ranking)
- **智能上下文关联**：根据当前编辑器活动文件，计算 Thread 相关性并进行“软置顶”。
- **意图图标识别**：AI 自动识别对话主题（BugFix 🐛, Feature ✨, Refactor 🛠️）并替换默认图标。

---

## 💎 进阶设计优化 (Top-tier Refinements)

### 1. 材质与深度系统 (Materiality & Elevation)
- **Header 磨砂处理**：Header 容器应用 `backdrop-filter: blur(20px)`，配合底部的细微光边，建立 Z 轴覆盖感。
- **浮动面板设计**：所有下拉菜单具备 `elevation-high`（深色投影 + 0.5px 内部高光边框）。

### 2. 交互动效物理学 (Motion Physics)
- **共享元素转换 (Shared Element Transitions)**：
    - 使用 `framer-motion` 实现搜索图标到搜索框的平滑拉伸变形。
    - 模型切换采用垂直方向的位移淡入淡出（Slide-up & Fade），模拟物理滚轮。

### 3. 动态密度控制 (Density UI)
- 支持“紧凑模式” (32px 高度，仅标题) 和“舒适模式” (48px 高度，含预览)，适配不同屏幕尺寸。

## 📐 设计规范 (Design Tokens)

| Token | 值 | 描述 |
|------|------|------|
| `--sidebar-header-h` | 68px | 品牌行 + 控制行总高 |
| `--capsule-bg` | `rgba(45, 45, 45, 0.6)` | 胶囊背景色（含透明度） |
| `--glass-blur` | `20px` | Header 磨砂玻璃模糊度 |
| `--motion-main` | `[0.23, 1, 0.32, 1]` | 统一弹性动画曲线 |

---

## ⚡ 性能优化策略

1. **Memo 化渲染**：对 `ThreadItem` 进行深度 `React.memo` 优化。
2. **Web Worker 分类**：Thread 意图识别和相关性计算放在 Web Worker 中进行。
3. **硬件加速**：Header 层开启 `will-change: transform`，确保磨砂滚动不掉帧。
