## 3. E2E 失败处理说明 (已忽略)
### 3.1 失败原因分析
- **环境超时**: 多数失败为 `TimeoutError`，系 Headless 模式及高负载导致。
- **Store 未就绪**: 修复了 `setState of undefined` 问题，但部分旧脚本仍因加载时机过快报错。
- **Mock 链路断裂**: 由于 PIVO 2.0 强化了 ID 校验，旧 E2E 脚本通过 `window` 直接注入的“非法”数据无法被识别。
